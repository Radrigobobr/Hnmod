# AK Prototype — Horizon Android SDK ABI 4

Прототип мода для Rayan-XOO/Horizon: предмет AK Prototype, 3D-модель из кубоидных элементов, текстура, счётчик 7.42 мм, автоматический огонь, перезарядка, HUD и отдача.

## Сборка
Из корня репозитория Horizon установите Rust target `aarch64-linux-android`, `cargo-ndk` и Android NDK. Затем:

    export ANDROID_NDK_HOME=/path/to/android-ndk
    bash mods/ak-prototype/build.sh

Результат: `mods/ak-prototype/target/ak_prototype.hnmod`.

## Проверка в игре
Установите `.hnmod`, перезапустите Horizon и включите AK Prototype в Options → Mods. В мире с читами/правами оператора:

    /give @s ak_prototype:ak_prototype

Удерживайте использование предмета для автоматической стрельбы. R или `/ak_reload` — перезарядка. Магазин 30, запас 120.

## Ограничения текущего прототипа
SDK предоставляет события использования предмета и вызов игровых команд, но не отдельный API огнестрельного оружия. Для прототипа используется сущность стрелы как снаряд и встроенный путь команд; это требует одиночного мира с читами/правами оператора. Модель — 3D-модель из кубоидов, не скелетная анимированная модель. Для запуска на Android обязательно собрать ARM64 `.so`; исходники сами по себе не являются готовым устанавливаемым `.hnmod`.
